Security

Why it's safe to connect your App Store Connect account

Handing an API key to a new tool should feel uncomfortable. Here's exactly what ShipCheck does with yours — nothing hidden.

Storage

Kept in your Keychain, not a plain file

Your .p8 key is stored in macOS Keychain with access control, unlocked only after you unlock your Mac — never written to disk as a plain file.

In transit

Signed locally, never transmitted

ShipCheck signs its own request token on your Mac. Only that signed token — never the private key itself — is sent, straight to Apple.

Architecture

No backend, ever

There is no ShipCheck server to breach. Every App Store Connect call goes directly from your machine to Apple's API.

Not a new idea

The same credentials fastlane already asks for

Key ID, Issuer ID, and a .p8 file are the exact three values fastlane — the tool most professional iOS teams already trust — has used for years. ShipCheck's Keychain-backed storage is more restrictive than fastlane's typical plain-file setup.

The tradeoff, stated plainly: ShipCheck doesn't run inside Apple's App Sandbox — it needs full filesystem access to read your Xcode project. That's exactly why the setup steps below have you create a key scoped to the Developer role rather than Admin: least privilege, so there's less at risk even in a worst case.

Setup

Connect your App Store Connect account

ShipCheck needs three things from Apple to read your app's real data. Here's exactly where to find them.

Open your API keys page

In App Store Connect, go to Users and Access → Integrations → App Store Connect API.

Generate a key

Click Generate API Key, give it a name, and grant it Developer access — the minimum role ShipCheck needs. Avoid Admin: a key scoped to Developer cannot touch users, agreements, or finances, so there is less exposure if it were ever compromised.

Copy the Key ID and Issuer ID

Both appear right on that page next to your new key, e.g. Key ID: 2X9R7B4K3P and Issuer ID: 69a6de….

Download the .p8 file — now

Apple only lets you download this once. Save it somewhere you won't lose it before you navigate away from the page.

Paste all three into ShipCheck

Open ShipCheck → Settings → App Store Connect, enter the Key ID and Issuer ID, and choose the .p8 file.

Why does ShipCheck need this? Apple's App Store Connect API requires every request to carry a signed token proving it's really you. ShipCheck builds and signs that token locally, on your Mac, using the key you just downloaded — the file itself is stored in your Keychain and never transmitted anywhere except directly to Apple.
